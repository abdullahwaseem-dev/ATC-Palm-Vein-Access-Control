# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report vulnerabilities privately through **GitHub → Security → Report a vulnerability** (private vulnerability reporting) on this repository. Include:

- a description of the issue and its impact
- steps to reproduce, or a proof of concept
- affected version / build flavor and device model

You will receive an acknowledgement within 5 business days. Please allow reasonable time for a fix before any public disclosure.

## Scope

In scope: the ATC Palm Access application code in this repository (Flutter/Dart and Kotlin).
Out of scope: third-party vendor SDKs and firmware (report those to HFSecurity / Hibory), and physical attacks on terminals without the documented hardening applied.
